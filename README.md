# YenKawa Aromatics

Static company website served at https://yenkawaaromatics.com/ with GitHub Pages.

- Home: a single-screen B botanical hero with the original white logo, Verdana wordmark and two-line slogan.
- Navigation: bottom-left menu button opens a native modal drawer. Escape, the close button and the background outside the drawer close it.
- The drawer has five approved categories: About Us, Personal Care Fragrances, Essential Oils, Personal Care Ingredients and Contact Us. About and Contact retain their existing studio.html sections.
- The three product categories each have a clearly labelled content-in-preparation page until product content is provided.
- The hero is a local, original AI-generated image selected during the design review. The logo remains the original asset.

Desktop typography uses Verdana: YENKAWA 32pt bold, AROMATICS 26pt regular, and the slogan 36pt regular. The wordmark grid places AROMATICS directly under the N in YENKAWA. Smaller viewports use proportional responsive sizes.

Preview with any static HTTP server from this directory. There is no build step or package installation.

GitHub Pages currently publishes the root of the gh-pages branch. After validation, push the same commit to main and gh-pages without force pushing. Keep the CNAME file unchanged.
Menu typography: desktop Chinese uses Microsoft JhengHei and English uses Verdana, both 28px regular. On devices with a mouse, hovering or keyboard-focusing a link crossfades the Chinese label to English in 200ms without changing its layout. On phones, only the Chinese label is displayed at 24px. The drawer copyright is 13px, bottom-right on desktop and on its own row above the close control on phones.
